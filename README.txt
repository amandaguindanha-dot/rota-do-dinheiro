ROTA DO DINHEIRO

Arquivos:
- index.html
- manifest.webmanifest
- service-worker.js

Como publicar sem login:
1. Netlify Drop: arraste esta pasta descompactada para o serviço de deploy.
2. GitHub Pages: envie os 3 arquivos para um repositório e ative Pages.
3. Cloudflare Pages: envie a pasta como site estático.

Depois de publicado em HTTPS, no celular:
- iPhone: Safari > Compartilhar > Adicionar à Tela de Início
- Android: Chrome > menu > Instalar app / Adicionar à tela inicial

Os dados ficam salvos localmente no navegador/aparelho via localStorage.
Não há login, banco de dados nem envio de dados a um servidor.
